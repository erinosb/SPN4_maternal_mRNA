# 01 Comparison of SPN-4, LIN-41, and OMA-1 associated RNA cohorts

The analysis in this subdirectory takes input data from the 01_input directory, runs scripts from 01_scripts, and produces output plots (03_figures) and tables (04_output_data). Figures and data are included in the manuscript as **Fig. 1**, **Fig. S1**, **Fig. S2**, **Fig. 3F**, and **Table S1**.

## Requirements 

Language - R

 * corrplot
 * RColorBrewer
 * pheatmap
 * tidyverse
 * hrbrthemes
 * viridis

 * DESeq2
 * extrafont
